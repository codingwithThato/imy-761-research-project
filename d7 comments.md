## The comments, ranked by how much they'll cost us

### 1. Sub-question 4 never gets a direct answer (page 9). This is the most serious one.

> "This section is lacking an answer to the research question - you need to bring together all these themes to answer the RQ."

- **Rubric rows affected:** "Analysis is used to provide answers to the RQ" (/5), and partly "Significance" (/5).
- **Problem:** the five themes are each well described, but no paragraph pulls them together into one answer. The closing paragraphs try, but they're mixed in with the questionnaire comparison. The sentence "Both kinds of feedback (questionnaires and semi-structured interviews) did the same job…" also confuses the data sources with the two feedback conditions.
- **Fix:** add a short paragraph titled "Answer to sub-question 4" that answers the question directly. For example: both conditions made failure understandable, and competence was limited by the controls rather than the feedback. The conditions differed mainly in how players saw the companion (a helper vs. pointless) and in how positively they described failure. Motivation depended mostly on the cost of failure and a sense of progress. Then put the link to the questionnaire results in its own sentence.

### 2. The wrong statistical test may have been used (page 6)

> "You first need to check for normality using Shapiro-Wilk and if it is non-normal, you need to use the Mann-Whitney U test instead."

- **Rubric row affected:** "Analysis is performed correctly" (/5).
- **Problem:** with n = 5 per group on Likert-type scales, normality is doubtful, so we'll probably end up using Mann-Whitney U.
- **Fix:**
  - Run Shapiro-Wilk on each subscale in each group (6 tests) and report the results.
  - For any subscale that isn't normal, report Mann-Whitney U, *U*, *p* and an effect size (*r* = Z/√N), with medians/IQR alongside or instead of M/SD.
  - Update the method paragraph, Table 1, the Figure 1 caption, and Exercise 1, which currently says "t-tests".
- The overall conclusion (no significant difference) will almost certainly stay the same, but the numbers and wording will change.

### 3. Report the quantitative results as paragraphs (page 6)

- **Fix:** turn them into connected prose, in the same style as the VR example in the template.

### 4. Theme descriptions need more depth (page 8)

> "You did a good job of analysing the feedback here. I would encourage you to add a bit more detail to each theme description though. Start with a summary of what the theme is about, then discuss some quotes, contrasting the different opinions, and then bring it all together at the end."

- This comment opens with praise, so it's polish rather than a rework.
- **Fix:** give each theme the same four-part structure:

  4. A closing sentence that sums up the theme.
